# Roteiro

O que já existe está no [README](README.md#o-que-é-conferido). Abaixo, o que ainda não é coberto e por quê. Contribuições são bem-vindas; abra uma issue antes, com a referência normativa.

| Item | Situação | Motivo |
| :--- | :--- | :--- |
| Imposto Seletivo (grupo `IS`) | planejado | Começa em 2027; a calculadora oficial já tem as tabelas, falta escrever as regras. |
| NFCom, NFAg, NFGas, DERE, DIR, Duimp | planejado | A calculadora oficial ainda não traz esquema para esses documentos. Os códigos já existem na tabela. |
| Recálculo da devolução de tributos (`gDevTrib`) | aguardando fonte | A calculadora oficial não publica a fórmula; não recalculamos para não gerar alarme falso. |
| Validação XSD do NF3-e | aguardando fonte | O pacote oficial traz só os tipos, sem o elemento raiz. |
| Alíquotas por UF e município | planejado | A base oficial tem as alíquotas de referência por ente; útil a partir de 2027. |
| Relatório em Excel (.xlsx) | ideia | Hoje há CSV pronto para abrir no Excel; .xlsx exigiria dependência. |
| Interface em inglês | ideia | O público principal é brasileiro; a documentação já tem versão em inglês. |
